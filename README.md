# Основы работы с множествами и объединениями (JOIN) в SQL

## Описание
В учебном проекте изучила операции над множествами и способы объединения данных в PostgreSQL. Написала SQL-запросы с использованием UNION, INTERSECT, EXCEPT, JOIN, NATURAL JOIN, подзапросов, а также операторов IN и EXISTS. На примере базы данных пиццерий, клиентов, меню, посещений и заказов научилась находить пересечения и различия между данными и получать связанные сведения из нескольких таблиц.

## Полученные навыки
- Операции над множествами - использовала UNION, INTERSECT и EXCEPT для объединения данных, поиска пересечений и различий между выборками
- Работа с дубликатами - изучила различия между сохранением и удалением повторяющихся строк при выполнении запросов
- Объединение таблиц - применяла JOIN для получения связанных данных из нескольких таблиц и изучила особенности NATURAL JOIN
- Подзапросы и проверка условий - использовала вложенные запросы, IN и EXISTS для поиска данных по заданным условиям
- Сортировка и формирование результатов - задавала порядок сортировки по нескольким столбцам и формировала вычисляемые текстовые поля

## Этапы проекта
1. Изучение операций над множествами, разбор способов объединения выборок, поиска пересечений и различий
2. Работа с уникальными и повторяющимися данными, обработка дубликатов и особенности операций над множествами
3. Поиск пересечений и различий, написание запросов для сопоставления заказов и посещений по датам и идентификаторам клиентов
4. Объединение таблиц, использование JOIN и NATURAL JOIN для получения связанных данных
5. Применение подзапросов и проверка результатов, сравнение способов поиска данных с IN и EXISTS

## Заключение
Проект помог углубить знания SQL и научиться сопоставлять данные из разных таблиц и выборок. Закрепила навыки работы с операциями над множествами, соединениями таблиц, подзапросами и условиями поиска.
